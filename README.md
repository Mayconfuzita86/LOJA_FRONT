# 🛒 Loja Front-end (E-commerce)

Interface de e-commerce desenvolvida em **React**, estruturada com componentização modular, gerenciamento de estado global via **Context API** e integração com API REST em Java.

---

## 🚀 Tecnologias Utilizadas

* **React** (v18+)
* **JavaScript (ES6+)**
* **HTML5 / CSS3**
* **React Icons**
* **Fetch API** para consumo de serviços backend

---

## 📋 Pré-requisitos

Antes de iniciar, certifique-se de ter os seguintes itens configurados em sua máquina:
* [Node.js](https://nodejs.org/) instalado (versão LTS recomendada).
* Banco de dados MySQL configurado com o SCHEMA `store` criado.
* O microsserviço/API backend rodando localmente. Repositório da API: [API Store](https://github.com/Mayconfuzita86/API_STORE)[cite: 3].
